# Phase 2: Appwrite Backend Integration

## Project

IP Quest

## Objective

Integrate Appwrite services into the existing Next.js application.

## Appwrite Services

- Appwrite Authentication
- Appwrite TablesDB
- Appwrite Storage
- Appwrite server-side SDK where required

## Initial Database Decision

Use Appwrite TablesDB for the initial MVP.

Native PostgreSQL may be evaluated later after checking plan availability, pricing, and migration requirements.

## Subphases

### 2.0 Documentation and Architecture Preparation

Prepare local documentation and integration rules.

### 2.1 Appwrite Project Configuration

Configure the Appwrite project, web platform, and project identifiers.

### 2.2 Database Setup

Create the database, tables, columns, indexes, and permissions.

### 2.3 SDK Integration

Connect the Next.js application to Appwrite.

### 2.4 Authentication

Implement registration, login, logout, and session handling.

### 2.5 Learning Content

Move topics, lessons, and questions from mock data into Appwrite.

### 2.6 Quiz Backend

Implement secure answer validation, scoring, and attempt persistence.

### 2.7 Progress and Gamification

Implement progress, XP, achievements, and dashboard data.
