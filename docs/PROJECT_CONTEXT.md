# Project Context

## Project Name

IP Quest

## Project Title

An Interactive Intellectual Property Awareness Platform for School Students

## Project Objective

Develop a responsive web application that teaches school students about Intellectual Property through interactive lessons, quizzes, gamification, progress tracking, and an AI learning assistant.

## Target Users

1. School students
2. Teachers
3. Administrators in future phases

## Core Topics

- Copyright
- Patents
- Trademarks
- Originality
- Plagiarism
- Innovation
- Intellectual Property in daily life

## Current Development Approach

The project will be developed incrementally in phases.

The first priority is a functional and visually polished MVP. Advanced features must not be implemented before the core learning and quiz workflows are stable.

## Target Platforms

- Desktop browsers
- Tablets
- Mobile browsers
- Progressive Web App in a later phase

## Development Constraints

- Solo student developer
- Beginner-to-intermediate programming experience
- Prefer simple, maintainable architecture
- Use free or low-cost services wherever possible
- Avoid unnecessary complexity
- All features must be understandable and demonstrable during project evaluation
